# Logistics Data Cleaning & Visualization

## Project Overview
This project demonstrates data cleaning, preprocessing, exploratory data analysis, and visualization using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Project Objectives
- Identify and handle missing values.
- Detect and remove duplicate records.
- Investigate potential outliers.
- Calculate delivery performance KPIs.
- Visualize delivery status, shipping costs, and delivery times.
- Develop data-driven operational recommendations.

## Key Findings
- Total shipments: 9
- Delivered shipments: 6
- Delayed shipments: 3
- Delivery rate among delivered and delayed shipments: 66.67%
- Average delivery time: 6.28 days
- Highest average shipping cost in the sample: Dubai, ₹1,805

## Recommendations
- Investigate delivery delays.
- Verify unusually high shipping charges.
- Monitor shipping costs and delivery performance by city.
- Review outliers before making operational decisions.

## Dataset Disclaimer
This project uses a simulated dataset for educational purposes. The findings do not represent actual company performance.
